# Crypto Lab Escape

This repository contains the online quiz website for a cryptography escape room game.

Published GitHub Pages URL:

https://markospanagiotou.github.io/crypto_escape_game/

## Levels

1. Caesar Cipher
2. Vigenère Cipher
3. DES
4. AES
5. RSA

Each level page contains an HTML quiz. The correct answer reveals the key, password, or instruction needed for the cryptography challenge.
